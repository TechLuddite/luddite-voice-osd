# Changelog

## 0.1.1 — October 19, 2026

- Select Luddite Voice OSD automatically when enabled on a standard Omarchy/Voxtype installation, preventing simultaneous stock and replacement dictation popups.
- Save the previous Voxtype OSD preference and restore it on normal disable/removal. Preserve unrelated configuration and retain a recovery receipt if cleanup is interrupted.
- Apply service changes while dictation is idle and leave Omarchy's volume, brightness and other shared OSD features enabled.
- Keep the replacement popup hidden and show a setup notice when automatic selection cannot handle a custom installation.
- Confirm working dictation and the corrected single-popup setup on the user's desktop and laptop. Add normal plugin update instructions.

## 0.1.0 — October 19, 2026

- Publish the standalone Omarchy-themed recording and processing OSD for Voxtype.
- Follow the system volume OSD's shape, typography, spacing, borders and theme/display settings.
- Show input levels, elapsed time, quiet-input feedback, microphone status, processing progress and a nonfocusing Cancel button.
- Add static previews and animated demonstrations with matching Omarchy wallpapers and retained source credits.
